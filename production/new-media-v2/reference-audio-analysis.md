# 《运气的形状》参考片：音频与媒体分析

后续状态更新：用户已直接上传并指定 `bgm.mp4`，当前风格试片改用该文件及原创SFX，音乐源已可用。本文保留的是最初对参考片整体音轨的测量，不代表当前试片仍采用原参考混音。最新来源、0.048秒同步偏移和试片说明见 `music-reference.json` 与 `style-review.md`。

本报告用于第二节点的脚本设计。依据用户提供的可读取 MP4、FFprobe、FFmpeg 响度测量、波形/频谱起音分析，以及本机现有中文 ASR 模型的辅助检查；没有开始正式剪辑或量产素材。

当前工具不支持音频输入，不能进行可靠的人工试听。因此，下文把媒体事实、可测周期与编辑建议分开，不猜曲名、乐器、歌词或具体音效种类。

## 2. 声音来源与复用边界

- 文件内没有可选择的独立音乐、音效、人声分轨；提取这一条音轨，只会得到上传参考片的**整体立体声混音**。
- 波形中有大量短瞬态以及稳定重复周期。短瞬态可能来自音乐自身的打击声，也可能包含另外叠加的音效；仅凭这些指标不能逐一归因。
- 使用已有 `sherpa-onnx-paraformer-zh-small-2024-03-09` 模型，将全长分成 13 个十秒区段辅助检查。结果只有空串或短小、不连贯的字词，没有识别出连续、可信的讲解旁白。
- 这一结果最多支持“**本次检查未发现清晰连续口播**”，不能证明绝对没有人声、哼唱、歌词或原片音效。ASR 碎片不能当作歌词或真实台词。
- 因此，现在可以保留相同的**原片音轨**，但不能把它标为“已提取的纯净原 BGM”，也不能承诺无损移除原片音效。若后续要求只保留原音乐、全部音效重做，仍需原歌曲的独立音源或接受混音分离的局限。

## 3. 节拍候选与置信范围

分析将音频转换为 22,050Hz 单声道，仅用于测量；基于约 10ms 时间步长的对数频谱正向变化量，计算全频及分频段起音包络的自相关。

| 候选 | 依据 | 可用于脚本的程度 |
| --- | --- | --- |
| **约 113 BPM** | 全长主要周期约 0.532 秒；插值候选 112.84 BPM；多个 20 秒窗口重复出现约 113 BPM 峰，自相关约 0.69–0.75 | 周期性证据较强，可作为初步节奏网格；具体拍点仍需逐段核对 |
| 约 56.5 BPM | 约 1.06 秒的重复周期，和前项存在半速解释 | 适合按两拍一个动作的慢节奏理解，不能据此断言曲目原始 BPM |
| 约 75.2 BPM | 约 0.798 秒的另一强周期，低频段也出现 | 存在不同重音分组歧义；不宜与 113 BPM 网格混用 |

自相关系数不是正确率。这里对“存在稳定周期”的信心高于对“歌曲严格为某个 BPM”的信心；没有进行人工听辨、曲目识别或逐拍标注。脚本可以把约 **0.53 秒**当成一个动作单位，重点字用约 **1.06 秒**留出阅读空间，但不应每拍都切镜头。

## 5. 能量起伏与张弛安排

下表为分析用单声道音频的区段 RMS，只比较相对能量，不等同于主观情绪或整段响度。

| 时间区段 | RMS 概况 | 脚本阶段的安排建议 |
| --- | --- | --- |
| 0–10s | 约 -10.36dBFS | 开头钩子先抓住一个问题，视觉不必立刻铺满 |
| 10–16s | 局部二秒窗约 -12.7 至 -12.2dBFS | 给第一处理解或悬问留一点阅读时间 |
| 20–50s | 十秒窗约 -8.1 至 -7.9dBFS，整体更强 | 承接行为、反馈和数据聚集的递进，允许密度上升 |
| 31.65–33.78s | 较密集的强起音 | 可作为一次局部小高潮，而不是持续全屏抖动 |
| 50–80s | 十秒窗约 -9.8 至 -10.3dBFS | 用连续图形关系发展解释，减少硬切 |
| **80–90s** | 十秒窗约 **-12.12dBFS**；86–88s 二秒窗约 **-13.49dBFS** | 适合悬问、收束前的停顿或画面留白 |
| 90–100s | 十秒窗约 -10.59dBFS | 从停顿恢复，逐步展开答案 |
| 100–130s | 十秒窗约 -9.8 至 -9.6dBFS | 回收主题，形成稳定、完整的结尾 |

相对最强的二秒窗出现在 36–38s（-6.78dBFS）、44–46s（-6.81dBFS）、18–20s（-6.93dBFS）。这些值是测量峰段，不能自动解释为原作的叙事高潮；还需与视觉分析对应。

## 6. 后续混音的余量

对原始立体声音轨进行 FFmpeg `loudnorm` 输入测量，得到综合响度约 **-9.97 LUFS**、响度范围 **3.10 LU**、真峰值 **+0.65dBTP**。这些是输入值；本次没有把归一化结果写成新素材。

原音轨已经较响，直接在原响度上叠加新音效容易造成峰值过载。进入用户确认过的剪辑阶段后，应先为音乐保留余量，再对关键新音效做短促、有限的突出；不需要每次文字移动都发声。最终应重新测量完整混音的真峰值和响度，不能仅靠单轨音量百分比判断。
