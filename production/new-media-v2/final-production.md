## 本轮画面

恢复首轮“居中主体＋下方居中文字”的版式：手机、小猫、红心与数据关系在画心，正文84px宋体、米白和暖金，最长句在安全宽内保持单行。闭环的两句在画心先后出现，结尾职业名居中落定。未沿用R2的大幅浅纸拼贴和粗黑体主标题。

背景按16组段落交替纯黑与深色浅波点，组内稳定。波点仅缓慢漂移与轻微明暗变化，组间约1.2秒过渡，不随每一句频繁换底。线条以6–9px主线为主。

文字约0.55秒渐显、约10px微移后保持稳定；主体主要移动1.5–3秒缓动完成，不采用快速弹跳。31–39秒四句的阅读时长改为1.45／1.65／2.20／2.70秒。116–124秒三句分配2.5／2.2／3.3秒，较长句有更多阅读时间。18–23秒保持真实五秒停留；128.8–130秒不新增信息与音效。

场景从刷手机到小猫停留、点赞留下，再到信号汇流、匿名汇总、总体趋势与变化、回看内容验证、胶片换开头和留长、回应回流与内容闭环。所有统计形状是叙事示意，不是假称真实账号数据。光效只强调点赞、聚合和闭环等落点。

## 复现

`npm run video:prepare` 根据本机保留的用户上传音乐／FLAC生成全长音乐与原创SFX；源文件路径和哈希见 `music-reference.json`。本机音轨已生成并完整解码通过。新机器需恢复同一用户上传音乐，必要时执行 `npm run video:prepare -- --music-input /实际路径/bgm.mp4`；生成器会核对源文件SHA。不能以440Hz测试音或旧版配音替代。

`npm run video:build` 检查类型、渲染7800帧、合成音轨、抽取JPEG并执行全AV校验。`npm run video:render` 可复用按源文件指纹缓存的图轨，仅重封装声音；`npm run video:verify` 检查130秒／7800帧、参数、所有帧音画解码、文案哈希、音乐来源、音频余量及真实预览帧。

正式组合为 `NewMediaV2Final`。图像使用Remotion的DOM `Img`；此前R2的CanvasImage图形后端出现过超时，完整成片改用经过短段验证的DOM图像路径。未增加依赖、未更新固定版本的官方Skill。旧版带配音流程保留为 `npm run video:legacy:build`，不作为当前默认成片。

当前制作状态以 `approval-state.json` 为准；完整输出只有在真实渲染和验证通过后才交付。验证通过只说明文件技术完整，不代替用户对成片的主观反馈。
