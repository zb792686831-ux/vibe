## 此轮改动

- 背景：暖米白纸感、淡鼠尾草色块，转到墨蓝／深青渐变与清晰可见的浅色波点；厚弧形色块增加纵深。
- 排版：大猫咪相纸与胶片占左侧，右侧宋体铺陈、粗黑体强调；后段切到左纸条与右信号环，文字成为构图主体。
- 素材：使用同一原创猫贴图、新生成的透明立体珊瑚红心；相纸、胶带、胶片、停留05s和重看贴纸回应叙事，不增加额外叙述文案。
- 动效：文字沿空间三次Bezier进入并缓停；相纸沿弧线上划，红心延迟沿曲线留在画面；粗路径依次描出，悬问出现后稳定阅读。
- 光效：只在0.65秒心形触发及5.72秒反应聚合附近加暖光／闪点，关键词“反应”短暂提亮；其他文字不持续发光。
- 线条：主要路径8–12px，贴纸描边5px，保留阴影形成层次。

## 复现与检查

`npm run typecheck` 检查源码；`npm run style:r2:render` 输出R2试片；`npm run style:r2:frames` 从导出视频重做三张交付JPEG；`npm run style:r2:verify` 完整解码三张JPEG与600帧音画、核对参数、文案批准哈希及用户音乐来源、比对图片和视频帧、测量音频余量。技术检查已通过，结果见媒体报告。初次独立Still与软件后端视频存在微小像素差异，交付图片已统一为实际MP4抽帧。

首次系统默认图形后端双路渲染在第108帧等待超时；同一帧单图可成功。本轮导出改为单路 `--gl=swangle` 软件图形后端，避免将失败进程当作完成。未全局修改其他视频的渲染配置。
