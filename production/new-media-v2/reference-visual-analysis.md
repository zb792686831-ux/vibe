## 可观察事实：总体视觉语言

### 字体与文字

中文主体具有明显的**宋体／明体类衬线特征**：横细竖粗、笔画收笔尖锐，既用于大标题，也用于底部叙述句。大标题较厚，说明文字较细；不是全片统一黑体粗字。英文／法文出处有衬线斜体，小拉丁副标题使用大写与较宽字距。年份与百分比也是有衬线数字。

文字有四个层级，随叙事切换，并非每屏都放同一位置的巨大标题：

1. 片名：02:08 的「运气的形状」约占画面宽度一半，字高约画面高度的 13%–16%，集中在上中部，下方保留曲线与说明。
2. 关键论断：01:37 的两行中文约占画面宽度一半、画面高度约 16%–20%，成为画面主角，其他内容退为细线与暗部。
3. 解释句：多数底部居中的短句，常约占宽度 45%–65%，字高约高度 4%–6%；00:25、00:49、01:21 都能看到图形主体与底部叙述的分工。
4. 注释：左上年份／地点、右上书名与出处、图内数据标签明显更小；只承担背景和论证信息，不争夺第一视觉焦点。

重点词会局部变金色，而不是整句反复换色。文字出现时可见由模糊到清晰、微小粒子或光点伴随的揭示；主体完成后存在稳定可读的停留。

### 色彩与背景材质

全片主体为接近黑色的暗底，场景间有暖褐与微冷黑蓝的变化；明亮整屏浅底并不构成主要段落。背景具有细颗粒、边缘暗角、少量漂浮尘点／星点、局部柔和光晕。它有暗室、旧纸或旧书页的触感，但不能据此断言原作者使用了哪种真实扫描纹理。

主文字与主线条是米白、象牙白和暖金色。金色通常包含明暗与轻微发光，不是单一平涂黄。少量低饱和砖红／暗红用于对比、输赢与负向路径（00:25、00:49、01:03）。色彩承担信息区分；没有可观察到的大面积珊瑚红／电光青作为整片主系统。

### 贴图与图形

可观察到三种材质混合：

- **有体积的物件**：象牙色骰子有真实明暗面、红黑点、地面投影；钱币／筹码有金属或浮雕触感，部分古代签状物件呈骨质或木质质感。它们不像纯线性图标。
- **精细线稿与数据图**：几何骰子、树状分支、点阵、罐子轮廓、坐标折线、高尔顿钉板、钟形曲线，线宽较细，主要使用米白／金色。
- **出版物式标记**：角落年份、书名引用、红色小印章、细边框、短横线与刻度，让画面像会运动的图解书页。

贴图没有统一的粗白描边或亮色卡通贴纸边。图文会在同一场内形成前后层次：01:05 树形分支为主，左侧比分逐步退暗；00:49 两个对照面板为主，掉落钱币只在边缘辅助叙事。

## 动画语法与节奏：基于连续帧的结论

1. **先给物，再把它抽象成关系。** 开场从立体骰子到细线骰子与概率，再进入片名；这比“先贴一个大概念，再摆图标”更有观看动机。
2. **一场内逐级揭示，主体位置稳定。** 01:00–01:04 的树形图靠线条、节点和重点路径依序生长解释推理；并非每一句都切新场。
3. **快的是局部动作，慢的是理解与阅读。** 片名在约一秒多的区间中迅速成形；底部句子和树形布局会跨多个采样保持稳定。不能把参考概括成“全程快切、所有字都弹跳”。
4. **运动承担因果。** 掷骰子的朝向变化、分支的展开、小球逐个落下与累积都直接表达内容；光尘只是低强度气氛层。
5. **用密度改变建立张弛。** 两面板、骰子阵列、树状分支和落球是信息密集段；01:37 中央论断和 02:01 单骰子明显留空。视觉密度的变化比增加转场种类更显著。
6. **场景通过淡隐、光晕、模糊清晰变化与图形转译衔接。** 抽样未提供逐帧测量，不给每种转场虚构固定帧数；实际落点应在节点 2 脚本明确、节点 3 样式确认后再做测试。

## 拟采用方案：需节点 2／3 确认后才能制作

以下是从参考抽象出的新版方向，**并不是声称参考片本身包含小猫、手机、红心或新媒体运营内容**。

### 保留的视觉规律

- 采用暗底、米白与低饱和暖金作为底层系统；若要使用红心的红，只让其作为一个有叙事意义的小高亮，避免把全片改成红／青双色现代卡片模板。
- 中文优先测试可合法使用的宋／明体类字体，以保留细横粗竖和书页气质；实际字体、字重和三种字号须给用户看样式后确认。不能把字体名称当作参考中已识别的事实。
- 以一两个有材质的具象物件带观众入场，再逐步转成细线、点和流动路径：手机／小猫／红心 → 停留与重看信号 → 汇总反馈 → 内容调整 → 返回观众与小猫。
- 保留颗粒、暗角、柔和局部光与少量尘点，控制在可读性之后；不把重噪声、发光边框、频繁故障效果当成参考的核心。
- 重要句可成为一屏主角；解释过程将文字放入稳定阅读区，让贴图／数据图承担另一半信息，不把 40 条文案一律拆成同样字号、同样位置、同样入场的 40 张卡。

### 根据本题需要调整

- 本版用户已要求**不配音**。参考中许多较小的底部叙述文字不能机械照搬：本版文字需要独立承载理解，解释句须增大、延长稳定阅读，并减少同时存在的注释。
- 小猫动作作为开场钩子可以快；「你的反应，留下了」「刚才那几秒，去了哪里」宜减速／留白；信号汇聚时逐渐加密；「原因，还要回到内容里验证」再次放慢；结尾回到一只小猫与一个愿意留下的人。
- “数据去了哪里”的画面应区分平台记录行为信号和运营看到汇总反馈。可用匿名化点流汇成分布或趋势，不能画成运营精准监控单个用户的完整身份轨迹。
- 不复制参考的骰子、历史年份、书名、红印章或钟形曲线作为本题装饰。只有在它们解释本题时才使用相应图形；例如汇总反馈也不必强行变成正态分布。
- 新版是介绍这个职位，不是六步教学。不得因沿用旧版图形而把“定位／选题／内容／分发／互动／复盘”职责清单重新塞回已经确认的文案。
